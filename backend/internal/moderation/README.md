# moderation

Скарги, черга модерації та аудит рішень. Маршрути — `api/swagger.yaml`, тег `moderation`.

- **Скарга**: одна відкрита на пару користувач–ідея (повторна — 409), на власну ідею не можна. 5 відкритих скарг (`domain.AutoHideThreshold`) переводять схвалену ідею в `HIDDEN`, відкривають кейс із джерелом `REPORTS` і сповіщають автора. Підрахунок іде під блокуванням рядка ідеї, тож паралельні скарги ховають її рівно один раз.
- **Черга** (`state=PENDING|HIDDEN`): відкриті кейси, найстаріші першими, keyset-пагінація з підписаним курсором. Лише `MODERATOR`/`ADMIN`.
- **Рішення** (`APPROVED`/`HIDDEN`/`REJECTED`): закриває кейс із записом хто, коли і чому (`decided_by`, `decided_at`, `note`), закриває скарги, сповіщає автора. Для не-схвалення нотатка обов'язкова. Перше схвалення `PENDING`-ідеї збільшує `approved_ideas` автора (відновлення зі `HIDDEN` — ні). Модератор не може вирішувати щодо власних ідей.
- Скарга, на яку відповіло рішення, не блокує нову скаргу того ж користувача.
- Один відкритий кейс на ідею гарантує часткова унікальна індекс (міграція `000014`).
