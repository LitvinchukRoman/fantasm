# admin

Операторська панель. Усе читається з Postgres: добові зрізи аналітики, список людей, перемикач премодерації і стан процесу.

- `GET /api/admin/overview` збирає KPI, вердикт за два останні повні тижні, шість серій для графіків і короткі інсайти. Перед відповіддю доганяє зріз за сьогодні й учора.
- Вердикт «ростемо / стабільно / падаємо» — зважена сума обрізаних дельт. Менше ніж 30 відвідувачів або 5 активних у базовому тижні дає «замало даних», а не напрямок.
- `ADMIN_EMAILS` (див. identity) не можна понизити звідси. Інші ролі змінює наявний `PATCH /api/admin/users/{handle}/role`.
