# legacy

Заморожений фронтенд MVP NaUKMA Ideas (Next.js 15, каталог `web/` з приватного репозиторію `naukma-ideas`).

Це довідник поведінки і текстів. Новий інтерфейс Fantasm робиться в `../frontend/` і не продовжує цей дизайн. Бекенд MVP (Spring) сюди не входив: правила продукту зібрані в `../FULL_CONTEXT.md`.

Шрифти Fixel у `app/fonts/` — сторонні файли MacPaw з того знімка. Новий дизайн їх не успадковує.

Щоб просто подивитись старий клієнт локально: `npm install && npm run dev` у цьому каталозі. Для роботи потрібен був API MVP; без нього стрічка порожня.
