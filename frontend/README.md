# frontend

Новий клієнт Fantasm: React + TypeScript (Vite).

Зараз на екрані лише назва і перевірка, що Go-сервер живий. Дизайн продукту ще не початий. Поведінка описана в `../FULL_CONTEXT.md`.

```bash
npm install
npm run dev
```

Dev-сервер проксує `/api` і `/healthz` на `http://localhost:8080`.
